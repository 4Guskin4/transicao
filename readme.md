Descrição do Projeto
Este projeto consiste em exercícios práticos para desenvolver e manipular transições e animações CSS/JavaScript, além de praticar o controle de versão com Git e GitHub.

---

 Módulos do Projeto

 1. Virar Carta (`/animacao`)
- Descrição: Implementação de uma transição 3D interativa de cartas acionada por botões ("Virar" e "Desvirar").
- Tecnologias: HTML5, CSS3 (perspectiva 3D e `@keyframes`) e JavaScript (manipulação de classes no DOM).

 2. Balão Subindo (`/balao`)
- Descrição: Simulação de um balão subindo continuamente pelo topo da tela utilizando animação em loop.
- Tecnologias: HTML5 e CSS3 (`@keyframes`, transformações e gradiente).
